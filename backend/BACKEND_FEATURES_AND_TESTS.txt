Legacy web application

ISSUES AND LIMITS
-----------------
- A cross-tenant payment-reference defect was found and fixed: a payment now
  rejects a member belonging to another organization. A regression test covers it.
- Dashboard monthly expense and additional-income totals now include all of
  today's timezone-aware transactions; regression coverage verifies both totals.
- Django warns that django-ckeditor bundles CKEditor 4.22.1, which is unsupported
  and has known unfixed security issues. Consider migrating to a supported editor.
- OpenAPI generation returns HTTP 200 but logs non-fatal serializer/type inference
  warnings for several APIViews and computed fields. It also auto-resolves an
  operation ID collision. Review schema annotations if client generation relies
  on a precise OpenAPI contract.
- The legacy template/form routes are inventoried above but were not each driven
  through every request method and workflow in this test run. Real SMTP, Cloudinary,
  external storage, and production database integrations were not exercised.
